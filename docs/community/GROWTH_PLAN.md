## Outreach Strategy

### Week 1 — Launch

- [ ] Enable GitHub Discussions
- [ ] Post announcement discussion
- [ ] Post ecosystem conversation starter
- [ ] Share on LinkedIn
- [ ] Share on X/Twitter
- [ ] Submit Show HN
- [ ] Post to relevant Reddit communities

### Week 2 — Ecosystem Outreach

- [ ] Identify 10 A2A-compatible agent projects
- [ ] Send personalized outreach (not mass emails)
- [ ] Invite them to add their agent
- [ ] Offer to help with Agent Card setup

### Week 3 — Community Building

- [ ] Respond to all discussions and issues
- [ ] Publish first "Agents in the Wild" post
- [ ] Share roadmap based on feedback
- [ ] Thank early contributors publicly

### Week 4 — Review

- [ ] Measure against 30-day goals
- [ ] Publish adoption retrospective
- [ ] Adjust strategy based on what worked
- [ ] Plan Phase 2 based on feedback

## What Success Looks Like

After 30 days, we should be able to answer:

1. Do developers want a neutral agent discovery layer? (Yes/No + evidence)
2. What trust signals matter most? (From discussions)
3. Who are our first power users? (Names + projects)
4. What's the biggest missing feature? (From feedback)
5. Should we invest in Phase 2? (Go/No-Go decision)
