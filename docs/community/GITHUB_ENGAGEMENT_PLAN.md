## Weekly Actions

### Respond to Discussions

Check Discussions tab daily. Reply to every comment within 24 hours.

| Discussion | Purpose | Current Status |
|------------|---------|----------------|
| #7 — Announcement | Official launch post | Monitor for comments |
| #8 — Research | Ecosystem conversation | Monitor for comments |

### Create Ecosystem Questions

Post a new discussion every 1-2 weeks to keep the community engaged.

**Next discussion ideas:**

| Week | Topic | Category |
|------|-------|----------|
| 1 | "What agent metadata do you wish existed?" | Ideas |
| 2 | "How do you test A2A agent compatibility?" | Q&A |
| 3 | "What would make you trust an unknown agent?" | Ideas |

### Welcome Contributors

When someone opens an issue or PR:

1. Reply within 24 hours
2. Thank them specifically
3. Answer their question or clarify the path forward
4. If it's a contribution, guide them through the process

### Monitor Issues

Check Issues tab daily. Tag with appropriate labels.

| Label | When to Use |
|-------|-------------|
| `good first issue` | Self-contained, well-scoped tasks |
| `help wanted` | Needs expertise the core team doesn't have |
| `question` | User asking for help or clarification |
| `discussion` | Open-ended topics that belong in Discussions |
| `enhancement` | Feature requests (defer to Phase 2) |

### Track Agent Submissions

When someone asks "can you add my agent?":

1. Thank them
2. Ask for their Agent Card URL
3. Add it to `config/seeds.json`
4. Re-deploy the demo
5. Log the submission in `VALIDATION_METRICS.md`

## What Not To Do

- Do not create fake issues or discussions to make the repo look active
- Do not ask friends to star the repo
- Do not close valid criticism
- Do not rush to add features based on single requests
