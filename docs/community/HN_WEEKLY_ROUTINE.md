# HN Weekly Routine

**Goal:** Consistent, valuable participation. Not volume — signal.

---

## Daily (15 min)

| Time | Action |
|------|--------|
| Morning | Scan HN front page. Look for AI/agent/infrastructure stories. |
| Save | Bookmark threads worth following. |
| Read | Read the top comments before posting. Understand the thread's tone. |

**Scan topics:**
- AI agents, agent protocols, agent safety
- Open-source infrastructure
- Python/FastAPI/SQLite discussions
- Distributed systems, trust, identity

---

## Weekly (1-2 hours)

| Day | Action |
|-----|--------|
| Monday | Check saved threads for new comments. Reply if you have something to add. |
| Wednesday | Search for new A2A/MCP/agent discussions. |
| Friday | Review the week. Log insights in `ECOSYSTEM_INSIGHTS.md`. |

**Weekly targets:**
- 3-5 meaningful comments
- At least 1 substantive technical comment (200+ words)
- 0 promotional comments

---

## Comment Quality Checklist

Before posting:

- [ ] Does this add new information or perspective?
- [ ] Am I speaking from direct experience?
- [ ] Is my tone curious, not certain?
- [ ] Would this be valuable if I had no project?
- [ ] Have I read the existing comments to avoid repetition?

If any answer is "no," rewrite or skip.

---

## What to Avoid

| Don't | Instead |
|-------|---------|
| Post just to be seen | Post only when you have something to add |
| Argue with downvotes | Consider why and move on |
| Promote your project | Contribute to the discussion at hand |
| Repeat what others said | Add a new angle or disagree thoughtfully |
| Post in every AI thread | Pick the threads where you have genuine expertise |
