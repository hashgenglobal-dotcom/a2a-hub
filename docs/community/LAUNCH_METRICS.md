## What We're Actually Tracking

Stars are vanity. The real signals:

| Signal | Why It Matters |
|--------|---------------|
| "Can you add my agent?" | Someone wants to be discovered |
| Thoughtful issues | People are reading the code |
| External PRs | Someone invested time |
| Repeated questions | These define v0.2.0 |
| Demo usage | Someone tried it |

---

## How to Measure

- **Stars:** GitHub API
- **Discussions:** GitHub Discussions tab
- **Issues:** GitHub Issues tab
- **External agents:** Manual tracking (submissions via discussions/issues)
- **Contributors:** GitHub Insights → Contributors
- **Demo visits:** Railway dashboard (if available)
